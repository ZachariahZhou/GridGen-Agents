# Publication scope

This is the **M102** curated public tree for GridGen-Agents, package version `0.1.0`.

Included: the complete current runtime and required catalogs, English interface and documentation, executable specifications, selected regression tests with fixtures, verification scripts, method description, compact numerical tables and grades, current figures, and five callable example models.

Excluded: `.env`, credentials, virtual environments, caches, local memory/checkpoints, raw provider conversations, large intermediate search directories, raw reference downloads, complete historical experiment archives and paper ZIP bundles. Git history retains earlier committed documentation; the current method and results are linked from the README.

The main research workspace and this publication tree are separate. Public presentation strings are English, while Unicode-escaped bilingual source patterns and fixtures retain decoded language inputs. Numerical catalog values and physical algorithms follow the current research implementation. Publication-specific presentation changes mean the runtime fingerprint is distinct from recorded experimental source fingerprints; both are retained for provenance.

`SNAPSHOT.json` hashes the selected publication files excluding itself. `docs/results/manifest.json` independently hashes the compact result bundle. The gallery manifest binds fresh figures to the current runtime and generated examples. Local verification and remote GitHub Actions have separate records.

The repository preserves its Apache-2.0 license and existing Git history. Reference material and dependencies remain subject to their own conditions in [THIRD_PARTY.md](../THIRD_PARTY.md).
